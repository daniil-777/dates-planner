# Third-party assets — the mannequin

`app/src/pages/intimacy/figureData.ts` is generated by `bake-figure.ts` from files belonging
to the **MakeHuman** project. It is not original work of this repository, and this file is
where that is recorded.

## What is used

| File | What it is |
|---|---|
| `data/3dobjs/base.obj` | the `hm08` base mesh — the sculpt itself |
| `data/rigs/default_weights.mhw` | bone weights, used to decide which vertex is which body part |
| `data/targets/macrodetails/{african,asian,caucasian}-{female,male}-young.target` | the morphs that make the two forms |
| `data/targets/ears/{l,r}-ear-scale-incr.target` | used as a definition of which vertices are an ear, not as a morph |

Fetched from `github.com/makehumancommunity/makehuman`. Every file is pinned by SHA-256 in
`bake-figure.ts` and the hash is checked on every run, so what is baked is always what was
reviewed.

## Regenerating

```bash
npx tsx app/scripts/bake-figure.ts            # fetches into .mh-cache/ on first run
npx tsx app/scripts/bake-figure.ts --report   # measurements only, writes nothing
npx tsx app/scripts/preview-figure.ts --zones # look at the result without a browser
```

`app/scripts/.mh-cache/` is a download cache and is not committed. The baked
`figureData.ts` **is** committed, so a normal build, a normal `npm ci` and CI never touch the
network — the script is only run when the figure itself is being changed.
